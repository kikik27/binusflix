BINUS University • Pemenuhan Rubrik Penilaian LO 3 (10 Pts Figma, 15 Pts Web, 15 Pts Mobile, 15 Pts Server/DB)

1. Ringkasan Eksekutif & Deskripsi Proyek

BINUSFLIX adalah platform hiburan digital berskala spesialisasi (mini specialized platform) resmi bernuansa merah tegas Almamater BINUS yang menyediakan informasi terpadu mengenai Film Layar Lebar, Serial Televisi, dan Musik. Pengguna dapat membaca ringkasan sinopsis, melihat kartu foto pemeran/karakter, menonton video trailer resmi (YouTube), mendengarkan sampel audio lagu 30 detik (Apple Music / iTunes), membaca ulasan komunitas, memberikan penilaian rating bintang, serta mengelola daftar koleksi tontonan favorit (watchlist) yang tersimpan di cloud MongoDB Atlas.

Aplikasi ini tersedia secara penuh dalam dua wujud:

  • Aplikasi Web: Menggunakan React JS (Vite), Tailwind CSS, dan React Router.
  • Aplikasi Mobile: Menggunakan React Native dan Expo (SDK 52+) dengan Expo Go QR support.
  • Aplikasi Server: RESTful API Node.js / Express.js dengan autentikasi JWT dan MongoDB Atlas.

5. Panduan Eksekusi Lengkap

A. Menjalankan Server Backend

cd backend
npm install
npm run seed      # Melakukan seeding data awal
npm run dev       # Berjalan pada http://localhost:5000

B. Menjalankan Web Frontend

cd frontend
npm install
npm run dev       # Berjalan pada http://localhost:5173

C. Menjalankan Mobile App Expo

cd mobile
npm install
npx expo start    # Pindai QR Code dengan aplikasi Expo Go

6. Verifikasi Penyimpanan Data MongoDB & Kesesuaian Soal

Apakah Database Menyimpan Data Ini?

YA, SELURUH DATA TERSIMPAN PERSISTEN PADA MONGODB ATLAS:

  • Koleksi users: Menyimpan registrasi, email, username, dan password terenkripsi bcryptjs.
  • Koleksi contents: Menyimpan 14 data film, serial TV, dan lagu lengkap dengan poster 100% aktif (200 OK), sinopsis, rating, dan trailer.
  • Koleksi favorites: Menyimpan preferensi personalisasi daftar tontonan (watchlist) milik pengguna.
  • Koleksi reviews: Menyimpan nilai rating bintang (1-5) dan teks ulasan komunitas.

Status Kepatuhan Terhadap Soal: 100% Sesuai Instruksi (Web React JS 6 halaman, Mobile Expo 6 screen, Backend Node/Express, Database MongoDB Atlas, Film/TV/Musik, Trailer & Audio Player, Watchlist & Review).
